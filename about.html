档案其一 · 其二 · 其三

关于我，写在这三页

不擅长自我介绍，所以把它拆成三个章节：从哪里来、正在做什么、想去哪里。

CH.01

起点 · 一行会动的字

第一次对编程产生兴趣，是初中时用 Scratch 让一只小猫在屏幕上走起来。那时不懂什么是变量，只知道“我写的句子，它真的照做了”。

后来是 Python 打印九九乘法表，再后来是 C 语言的指针。每次把抽象的东西变成能跑的程序，都像在黑暗里点亮一颗很小的星。

CH.02

现在 · 一边报错，一边前进

这学期在学 C 语言、数据结构、计算机组成原理和 Web 前端。最常待的地方是图书馆四楼靠窗的位置，桌上永远有一杯凉掉的咖啡。

这个网站是我的《计算机基础》课程设计：从配色、排版到每一张 SVG 插画，都是自己一行一行写出来的。它不完美，但每个像素都知道来历。

CH.03

未来 · 把复杂讲简单

短期目标很具体：把算法基础打牢，能独立完成一个前后端小项目，英语四级一次过。长期想成为那种“能把复杂问题讲得很简单”的工程师。

如果有一天，我写的东西能帮别人省下一点点时间，或者让某个人少皱一次眉，那这趟开拓就算没有白走。

代码是写给未来的信，注释是写给自己的便签。 —— 显示器边框上的贴纸
把每一次报错，都当成星图上的一个新坐标。 —— 记于某次通宵之后
喜欢的事，要慢慢做，做很久。 —— 手账扉页
